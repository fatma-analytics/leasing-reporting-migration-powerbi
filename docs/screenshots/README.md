# Maquettes de pages

Les fichiers PNG sont des **maquettes statiques** construites à partir du mart SQLite synthétique par `scripts/build_project.py`. Ils illustrent les cinq pages du rapport visé et les indicateurs calculés par le prototype. Ils ne sont pas des captures d’écran de Power BI Desktop et ne simulent pas l’interactivité de slicers ou la navigation.

L’image `avant_apres_production.png` compare une sortie tabulaire legacy de type Excel/BO alimentée par les lignes brutes à une vue mensuelle reconstruite sur le périmètre SQL nettoyé. La différence visuelle reflète les règles qualité; elle n’illustre pas un logiciel BusinessObjects réel.
